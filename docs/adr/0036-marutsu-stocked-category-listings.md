# ADR-0036: マルツオンラインは「明日出荷在庫品」に絞った分類一覧を読み、事実だけを記録する

状態: 採用 / 2026-11-16 / Issue #121 / userscript 0.7.12

[マルツオンライン](https://www.marutsu.co.jp/)(`marutsu`)を 7 店舗目として追加する。対象は大分類 7 つ(キット・開発ツール・電気部品・電子部品・電線・配線部材・半導体・コネクター)の、在庫品で絞り込んだ一覧だけにする。この ADR は、何を**どこから**読み、**どこまでを**全件とみなし、**何を記録しないか**、商品ページの**どこに**パネルを出すかを決める。

## 背景と境界

調査日は 2026-11-16(本人の Chrome での読み取り確認と、Wayback Machine に保存された一覧ページ 2025-03-19・2025-11-15・2026-01-29 の実物照合)。

- **規模**: 全商品は 12,808,263 件。大分類の件数は電子部品 4,048,753・コネクター 3,397,398・半導体 1,847,190・電気部品 1,133,036・電線・配線部材 613,225・開発ツール 59,865・キット 6,237 で、大半は DigiKey 等の取扱品(自社在庫なし)である。全件の収集は間隔 2 秒でも年単位になり、対象にしない。
- **在庫品の絞り込み**: 一覧の「在庫品で絞り込む」は店舗が「明日出荷在庫品」と呼ぶ条件で、URL は `GoodsListNavi.jsp?category=<path>&ids=1&page=<n>&perpage=50&sort_order=no_order` の形になる。2026-11-16 の在庫品件数は、電子部品 4,903・電気部品 3,187・コネクター 2,778・半導体 1,872・開発ツール 1,365・電線・配線部材 897・キット 378、合計 15,380 件である。
- **件数の上限**: 一覧は最大 4,000 件(50 件 × 80 ページ)までしか返さない。在庫品でも電子部品(4,903)は上限を超えるため、中分類から読む。中分類は全カテゴリ一覧(`GoodsAllCategoryList.jsp`)の大分類別アンカー(`#goodsClassName2Surround<6桁>`)から得る。電子部品の中分類は 22 件。中分類でも同じ絞り込みが効く(ACインレット・アウトレットは 25 件で確認)。中分類でも上限に達したら、その実行は不完全として止める。
- **robots.txt**: 店舗ページの巡回は禁止されていない(禁止は `/edc_bo/`、`/wp/wp-admin/`、`/SimilarList.jsp` のみ)。sitemap の宣言はあるが、工具・産業系を含む全店分で 10 万件級の見込みであり、在庫品の発見には使えない(ADR-0012 の「sitemap を正解とする」はこの店舗では採らない)。
- **サイトの保護**: サイトは Cloudflare の配下にある。データセンター側の出口からは JavaScript チャレンジが返ることがある一方、せんごくも Cloudflare 配下で通常の取得ができている。初回の収集実行で、プロジェクトの UA の通常の GET が通るかを確かめる。通らなければ実行は不完全として終わり、回避はしない。
- **各行**(`li#resultsRow_N.DETAILS_ROW`): 商品ページへのリンク(`/pc/i/<数字>/`)、型番と商品名、価格の段階、明細欄(メーカー名・型番・出荷予定日・品質ランク、および店舗によってはマルツコード・箱番号・最小発注数量)、即納在庫数。在庫数は数で出る(店舗が報告する数、`site_reported`)。DigiKey 取扱品の行は在庫数と出荷予定日の代わりに「最新在庫数を確認」「最新納期を確認」というリンク文言を出す。
- **同一性**: 商品ページのアドレスの数字が同一性でありページキーでもある。マルツコード(`M0004-0938` の形)は商品ページと現在の一覧に印字されるが、2025-03 – 2026-01 に保存された一覧には出ていないため、別名として保持するに留め、同一性にはしない。
- **価格欄**: 数量の段階ごとに税抜と税込が併記される(`1個以上 ￥429.00 (税抜) / 税込￥471.00`)。小数部は読んだ全行で `.00`(店舗が円未満を切り捨てて表示する)だった。
- **商品ページ**(`/pc/i/<数字>/`): 型番・商品名・メーカー・マルツコード・品質ランクが中央の列に、即納在庫数(営業所合計とは一致しない総数)と出荷予定日・数量別の価格表が右の列に出る。営業所別の内訳は記録しない。
- **境界**: 共通コア(`src/core`、`src/db`、`src/publisher`、`src/pipeline`、`userscript/core`、`userscript/ui`)に店舗名を書かない。拡張の権限は広げない(履歴の取得先は Pages のまま)。
