# ADR-0029: サイトが閉じた店舗は観測を止め、公開済みの履歴だけを再生成し続ける

状態: 採用 / 2026-11-04 / Issue #80

関連: ADR-0016(観測頻度は店舗ごとに宣言する)、ADR-0005(隔離しても公開は続ける)、ADR-0023(KSY)、`config/<store>.json`、`scripts/observed-stores.ts`

## 背景

Raspberry Pi Shop by KSY(`ksy`)は 2026-11-04 の 13:30Z・13:48Z・14:00Z に接続を受け付けなかった。オーナーは同日、サイトは戻らないと判断した(「いや、復旧しないよ」)。最後に観測できたのは 2026-11-02T00:57Z で、観測は 4 回、776 商品である。

変更前は次のとおりだった。

- KSY の `observation.cadence` は `every_two_days` だった。観測日のたびに KSY を巡回し、約 55 秒でタイムアウトして隔離(終了コード 3)になっていた。#78 以降は他店舗を止めないが、毎回警告が出ていた。
- `stores` を空にした手動実行は、`STORES` の全店舗を観測していた。
- KSY のマニフェストには `samplingIntervalDays: 2` があった。パネルはこれを「価格・在庫はおおむね2日に1回の観測です」と表示する。この文言はもう事実ではない。
- 既存の cadence(`weekly` / `monthly`)に変えても同じ問題が残る。今度は 1 週間または 1 か月に 1 回という、同じく誤った注意書きを公開することになる。

## 決定

- **`observation.cadence` に `stopped` を加える。** 意味は「この店舗はもう観測しない」。公開済みの履歴は残し、毎回のデプロイで `--republish` によって再生成する。
- **どの店舗を観測するかは `scripts/observed-stores.ts` が決める。** 判定はパイプラインと同じ設定パーサーで読んだ cadence による。ワークフローのシェルから `jq` による cadence の読み取り(既定値 `monthly` の二重定義)を取り除いた。
  - schedule: その cron の cadence を宣言した店舗だけを観測する。
  - `stores` を空にした手動実行: `stopped` 以外の全店舗を観測する。
  - `stores` に店舗を書いた手動実行: 書いたとおりに観測する。未知の店舗や `stopped` の店舗が含まれていればエラーにする。黙って飛ばすことはしない。
  - `republish=true`: 何も観測しない。
- **パイプライン自体も拒否する。** `--republish` 以外の実行(クロール・`--snapshot`・`--bootstrap`)と `crawl` コマンドは、`stopped` の店舗では何も取得せず終了コード 1 になる(`assertObserved`)。ワークフローの選択を誤っても、閉じた店舗へリクエストは出ない。
- **`stopped` の店舗は観測間隔を表明しない。** `samplingIntervalDays` も `sampling_interval*` の注意書きも出さない。`observation_window` と、観測期間(最初と最後の観測日、回数)は残す。cadence と注意書きの対応は `SAMPLING_CAVEAT` の網羅的な表で持つ。cadence を追加したのに注意書きを決め忘れると、型検査で失敗する。
- KSY を `stopped` にする。

## 理由

**観測していない店舗に観測間隔があると書けば、読み手は誤った読み方をする。** 間隔の表明は「この間隔で見ているので、記録に無い変化は無かった」という読み方を許す。閉じた店舗では最後の観測より後のことは何も分からない。言えるのは観測期間だけで、パネルはそれを「観測期間 2026-10-29〜2026-11-02(4 回)」と表示する。

**新しい注意書きキーは足さない。** v1 の旧版クライアント(0.7.4 が公開中、0.7.6 が審査中)は未知の注意書きキーを拒否する。`samplingIntervalDays` は省略可能なので、消しても旧版は同じように読める。契約の形は変わらない(契約版も据え置き)。「この店舗の観測は終了しました」という明示的な表示には、契約へのフィールド追加とクライアントのリリースが要るので、この ADR の範囲外とした。

**履歴は消さない。** 他店舗の商品ページの比較カードは KSY の記録を参照している(対応表 5,631 組のうち 886 組)。KSY を含む組に価格比較の条件(`pricePolicy`)を持つものは無いので、KSY の最終観測価格との差額や最安表示は出ない。比較カードは KSY の記録を「最終観測 2026-11-02 09:57」のように日時を添えて表示する(日本時間で読んだ場合)。

## 結果

- 観測日の run から KSY の約 55 秒と隔離の警告がなくなる。KSY のデータセットは毎回 `--republish` で再生成されるので、Pages から消えない。
- KSY の `datasetVersion` は一度だけ変わる。`samplingIntervalDays` がマニフェストから消えるためで、`runCount` と変化点は変わらない。
- 観測を再開する場合は、cadence を `every_two_days` などに戻すだけでよい。履歴は続きから増える。
- 残る課題(範囲外): 比較カードの KSY 商品リンクは閉じたサイトを指している。拡張機能の host permission とストア掲載文にも KSY が残っている。どちらも、表示や掲載文を変える次のリリースで扱う。
