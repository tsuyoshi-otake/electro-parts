# ADR-0028: グラフにポインターを重ねた位置の値を表示する

状態: 採用 / 2026-11-04 / Issue #76 / userscript・拡張 0.7.6

オーナーは 2026-11-04 に「グラフにマウスオーバーした時にラベルでるといいよね、マウスオーバーした線の箇所の値段とかね」と依頼した。0.7.5 までは、変更点の点に重ねるかフォーカスしたときに、その 1 点の値(`<title>` と `aria-label`)だけを読めた。点と点の間の線の値は読めなかった。

## 決定

### 対象と表示

単店の価格グラフ、店舗比較グラフ、在庫数グラフの 3 つ。描画域の上にポインターがある間、次の 3 つを描く。

- ポインター位置の縦線
- 表示中の各系列の線上の印
- ラベル: 1 行目に日時、2 行目から系列ごとの値。系列が 2 つ以上なら店舗名と色の印を前に付ける

日時の粒度は横軸と同じで、期間が 3 日未満なら時刻まで出す。ラベルは縦線の右に置き、右端に収まらなければ左に置く。縦方向はグラフの内側に収める。

### 値はグラフの描き方と同じ意味で読む

値は、グラフが描いているのと同じ意味で読む。次の変更点まで直前の値が続くものとし、補間はしない。新しいデータも足さない。

| 位置 | 価格 | 在庫数 |
|---|---|---|
| 値のある区間 | その時点で有効な価格。幅のある価格は「最小〜最大」 | 「在庫数 N」。店舗の上限なら「100+」(ADR-0027) |
| 線が切れている区間(未掲載・価格表示なし・数の表示なし) | 「価格の記録なし」 | 「在庫数の記録なし」 |
| その系列の最初の観測より前、最後の観測より後 | 「観測期間外」 | 「観測期間外」 |

- 描いた点から横に 4 単位(viewBox 座標)以内にポインターがあれば、その点の値を読む。観測が 1 回だけの店舗は点しか無く、最終観測で価格が変わった店舗は最後が縦線だけになる。どちらも点に重ねれば読める。
- 単店グラフは最後の観測で止める。その右の短い線は、最後の変化を見せるための描画上のものなので、ポインターがそこにあっても最後の観測の値を出す。

### 店舗の切り替えとポインターの種類

- 店舗の切り替えで隠した系列は、ラベルにも印にも出さない。全部隠した場合は何も出さない。判定はポインターを動かしたときの系列の表示状態で行う。
- マウスとペンは、グラフから離れたら消す。タッチはタップで出し、次のタップまで残す。タッチのポインターは指を離すと離脱扱いになり、すぐ消えて読めないためである。

### アクセシビリティ

- キーボードで点にフォーカスして読む方法と、点の `aria-label` は変えない。ラベルは `aria-hidden` にする。
- 単店グラフの根要素の `<title>` を外し、要約は `aria-label` だけで伝える。根の `<title>` はブラウザーが自前のツールチップとして出し、ラベルに重なるためである。

### 構成

- `userscript/ui/chartReadout.ts` は、ポインターの位置、描画域、ラベルの配置だけを扱う。
- 各時点の値の求め方は、3 つのグラフ(`userscript/ui/chart.ts`)がそれぞれの目盛りと一緒に渡す。
- どちらも店舗名を書かない共通 UI で、DOM API だけで組み立てる(ADR-0011)。
- ラベルは動かすたびに作り直し、離れたら空にする。止まっているグラフには余計な要素を残さない。

## 範囲外

- 価格グラフと在庫数グラフで縦線を連動させること
- データ・契約・取得回数の変更

## 結果

- 0.7.6 で出す。データ契約・取得回数・権限は 0.7.5 と同じ。
- 描画域の上には透明な受け取り面を置く。点はその下になるので、点に重ねたときのブラウザーのツールチップ(点の `<title>`)はマウスでは出なくなる。値はラベルで読む。
