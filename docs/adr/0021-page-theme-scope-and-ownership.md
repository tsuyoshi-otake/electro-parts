# ADR-0021: 店舗ページのテーマは閲覧ページだけに、1 つの実行体だけが掛ける

状態: 採用 / 2026-10-04 / Issue #27 / userscript 0.4.7

0.4.7 で、パネルの「ダーク」を店舗ページ全体に反映するようにした。この ADR は、その反映を**どのページに**、**誰が**掛け、**どう戻せるか**を決める。パネルの表示内容とデータ取得は変えない。

## 背景と境界

最初の実装は店舗ドメイン全体(`akizukidenshi.com/*` など)でコンテンツスクリプトを動かし、商品ページ以外にもテーマを掛けた。レビューで次の 4 件が見つかった。

1. ダーク配色の文字色が、基準背景 `#3e3e3e` に対して WCAG AA(4.5:1)を下回っていた。
2. 商品 URL なのにパネルを出せないページ(商品番号を読めない、挿入位置が見つからない)では、テーマだけ掛かって戻す手段が無かった。
3. 拡張機能とユーザースクリプトを両方入れると、両方がテーマを掛け、片方の「ライト」で元に戻らなかった。
4. カート・購入手続き・会員ページにもテーマが掛かり、在庫や値引きの色分けが一律の文字色に潰れていた。

境界: 店舗サイトへのリクエストは増やさない。店舗名はアダプター(`userscript/adapters`)にだけ書く。

## 決定

- **実行範囲は各アダプターの `matchPatterns` だけで決める**。トップ・カテゴリ・検索・商品などの閲覧ページを列挙し、カート・購入手続き・会員・問い合わせのパスは含めない。ビルドはこの一覧をそのまま拡張のマニフェスト `matches` と `@match` に写し、コントローラーも同じ一覧でアダプターを選ぶ。以前の `matchesSite` は削除した。範囲の定義は 1 か所になる。
- **パターンは Chrome の解釈の部分集合だけ受け付ける**(`userscript/core/urlPattern.ts`)。`https`、ホスト完全一致、パスとクエリを合わせた文字列に `*` だけをワイルドカードとして照合する。`?` は文字そのもの。トップページはクエリ付きを含めて `/` と `/?*` の 2 つで表す。部分集合の外にあるパターンは**何にも一致しない**(fail-closed)。
- **1 つの文書を担当する実行体は 1 つ**にする。`<html data-eph-owner>` を最初の `await` より前に同期的に確認して設定する。拡張の isolated world と Tampermonkey のサンドボックスは DOM を共有するので、この確認と設定は両者の間で排他になる。取れなかった側はテーマ・パネル・リセット操作・データ取得のどれも行わない。担当側が破棄されると属性は外れる。
- **ダークを掛けたのにパネルを出さないときは、必ず「ライトに戻す」を出す**。商品ページ以外、商品番号を読めない商品ページ、挿入位置が見つからない商品ページのすべてが該当する。押すとテーマと操作部品を外し、設定を `light` に保存する。テーマは掛ける前の属性値を覚えず、ライトでは属性ごと外す(担当が 1 つなので他者の値は無い)。
- **在庫・値引きなどの意味を持つ色はアダプターで残す**。一律の文字色規則より詳細度の高いセレクターで、店舗ごとに暗い背景で読める色を指定する。
- **配色はテストで固定する**。パネルのダーク背景が `#3e3e3e` であること、文字色が 4.5:1 以上であること、各アダプターのテーマ CSS の文字色が `#3e3e3e` に対して 4.5:1 以上であることを `tests/userscript/theme-contrast.test.ts` が見る。範囲は `tests/userscript/page-scope.test.ts` と `tests/e2e/page-theme-scope.spec.ts` が見る。

## 理由

範囲を「ドメイン全体で動かし、コード内で除外する」形にすると、除外漏れがそのまま購入手続きへの介入になる。閲覧ページを列挙する形なら、漏れは「テーマが掛からないページがある」側に倒れる。マニフェストに書いた範囲がそのまま審査と利用者に見える範囲になることも、権限の説明と実装を一致させる。

二重実行の防止を「先に入った方がパネルの要素を作ったか」で判定すると、パネルを作らないページ(商品ページ以外)では判定できない。テーマはパネルより先、`document_start` で掛かるので、判定も同じ時点で文書に置く必要がある。

## 結果

- 列挙していない閲覧パス(例: 新しい特集ページの形式)にはテーマが掛からない。必要になったらアダプターの一覧に追加する。追加はマニフェストの `matches` も変えるので、拡張は版を上げて再提出する。
- スイッチサイエンスと M5Stack の `/pages/*` は、問い合わせフォームを含み得るが特集ページが大半のため範囲に入れている。
- 旧版(担当属性を持たない版)と同じページで並んだ場合に備え、パネル要素の有無による確認も残している。
- ライト配色で押下中のテーマボタン(`#1f6feb` を `#eef2f7` 上)は 4.12:1 で、この ADR の範囲外として残っている。
