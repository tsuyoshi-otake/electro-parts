This is the pre-submission check of the 0.6.8 extension ZIP that Pages serves, as CLAUDE.md requires before a Chrome Web Store submission.

The evidence is kept under `~/tmp/electro-068/`:
- the script `live.mjs`;
- the downloaded ZIP `ext.zip` and its extraction `ext/`;
- `shots/`, which holds the screenshots and `results.json`.
