## What this release does not change

- The data contract (v1.1) and the set of caveat keys emitted: a daily store carries its interval in `observation.samplingIntervalDays`. Clients before 0.7.7 read it and show no interval note.
- Per-request pacing, caps and retry limits of every collector. One run is as long as before (2 h 55 min on 2026-11-07, limit 240 min); there is one run a day instead of one every second day.

## First daily observations

The cron at 2026-11-08T20:00Z (05:00 JST on 2026-11-09) is the first daily run: day count 59, Switch Science slice 3. The slices then run 0, 1, 2, 3 on the following days; SKU 11427 (slice 2) is read by the run of 2026-11-11T20:00Z, so its stock chart appears on 2026-11-12.
