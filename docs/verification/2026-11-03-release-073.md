# 0.7.3 release: store texts without the store list, after the Yellow Argon rejection (#69, PR #70)

The Chrome Web Store rejected 0.7.2 on 2026-11-03 for excessive keywords (Yellow Argon); see [the 0.7.2 record](2026-11-03-release-072.md). 0.7.3 changes only the public texts and the version:
- the manifest description ends with 「国内4店舗と海外2店舗に対応。」 instead of the six store names;
- the listing's 「■ 対応サイト」 gives the counts and the landing page URL instead of six names with domains;
- the landing page lists all six stores and states the wide-screen panel position on M5Stack and Pimoroni.

This record is the pre-submission check that CLAUDE.md requires, run on the ZIP that Pages serves. The evidence is kept under `~/tmp/electro-073/`:
- `pages-before/` and `pages-after/`: the store manifests and state, and the published ZIP;
- `local-ext.zip`: built from the merge commit's tree for the byte comparison;
- `pub-ext/`: the ZIP's extraction;
- `live.mjs`: the 0.7.0 functional script plus a manifest description check;
- `live-func/`: the run's screenshots and `results.json`.
