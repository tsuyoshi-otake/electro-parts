# 0.7.0 release: Pages ZIP on live store pages (#57, #61, #62, #63, PR #64)

This is the pre-submission check of the 0.7.0 extension ZIP that Pages serves, as CLAUDE.md requires before a Chrome Web Store submission. 0.7.0 contains 0.6.9 (#55), Pimoroni (#57), the GBP yen reference (#61), and the yen headline, card fee and stock chart settings (#62, #63).

The evidence is kept under `~/tmp/electro-070/`:
- the script `live.mjs`, rebuilt from the 0.6.8 one with the 0.7.0 checks added;
- the downloaded ZIP `ext.zip` and its extraction `ext/`;
- `local-ext.zip`, built from main for the byte comparison;
- `pages-before/` and `pages-after/`, the store manifests and state before and after the run;
- `shots/`, `shots-2/` and `shots-ksy/`, which hold the screenshots and each run's `results.json`.
