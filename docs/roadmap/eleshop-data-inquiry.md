## 件名

全商品の価格・在庫履歴サービス向けデータ提供（API・CSV等）のご相談

## 本文

共立電子産業株式会社 通販営業部 ご担当者様

電子部品ECの価格・在庫・掲載履歴を記録し、Webサイトおよびブラウザー拡張機能で表示するプロジェクト「electro-parts」を開発しています。
プロジェクト: https://github.com/tsuyoshi-otake/electro-parts

貴店の全商品を対象として、観測日時を併記した価格・在庫の履歴と商品ページへのリンクを表示する対応を検討しています。記録した価格を現在価格と断定せず、商品説明文・画像の転載は今回の相談対象に含めません。

個別の商品ページを大量に巡回する負荷を避けるため、API、CSV、JSON、商品フィード等による一括データ提供、または利用可能な連携サービスがあるかお伺いしたくご連絡しました。

1. 取寄品を含む全掲載商品について、商品コード、URL、商品名、メーカー・型番、税込販売価格、販売数量・注文単位、在庫状況・数量、情報の更新日時をまとめて取得する方法はありますでしょうか。数量割引や販売終了・掲載削除も識別できると助かります。提供可能な項目・対象範囲をお知らせください。
2. 希望更新頻度は2日に1回です。全件データまたは差分データの形式、更新間隔、取得回数・件数の制限、利用料金、申込条件があればお知らせください。
3. 取得した情報を履歴として継続保存し、観測日時と出典を添えてWebサイト・ブラウザー拡張機能に公開すること、および履歴表示用データをGitHub Pagesから配信することは可能でしょうか。他店との比較表示を行う場合の条件も確認したく存じます。
4. 一括提供がない場合、同じ目的で利用できる認定連携先、または貴店が指定する取得方法・頻度・対象範囲はありますでしょうか。

現在は公開サイトマップによるURL件数確認と商品ページ1件の表示構造確認までで、全商品ページの巡回は開始していません。貴店の運用に適した方法・条件に合わせて検討したいと考えています。

ご担当部署が異なる場合は、相談先をご案内いただけますと幸いです。
