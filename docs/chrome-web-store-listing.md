# Chrome ウェブストア 掲載情報(提出用の原本)

ダッシュボードの入力欄に貼る文言を、ここに 1 か所だけ持つ。提出は転記作業であって、その場で文章を考える作業にしない。
パッケージ側の要件(名前・説明の文字数、版番号、権限、リモートコード)は `tests/contract/chrome-web-store.test.ts` が機械的に検査しているので、
このファイルは**人が答える欄**だけを扱う。

- パッケージ: `npm run build:extension -- --zip dist/electronics-price-history-extension.zip`(公開済みの zip をそのまま出しても同じ)
- 掲載画像: `npm run build:store-assets` → `dist/store/`(スクリーンショット 4 枚とプロモーション タイル 2 枚)。ショップアイコンは生成しない。パッケージ同梱の `dist/extension/icons/icon-128.png` をそのまま上げる。
- プライバシーポリシー URL: <https://tsuyoshi-otake.github.io/electro-parts/privacy.html>(`public/privacy.html` が公開されたもの)
- 版: `userscript/version.ts` の `USERSCRIPT_VERSION`。**ストアは同じ版を 2 回受け付けない**ので、再提出のたびに上げる。

## 事前に必要なもの(人の作業)

1. Chrome ウェブストアのデベロッパー登録(初回のみ登録料 5 USD)。
2. Google アカウントの 2 段階認証を有効化(未設定だと公開できない)。
3. 連絡先メールアドレスの確認(ダッシュボードの「アカウント」→ 連絡先メール)。掲載ページに表示される。
4. 公開範囲は「公開」。有料機能・広告・アプリ内購入はなし。
5. トレーダーの申告(「アカウント」→ 設定)。個人の非商用公開なので**非取引業者**を選ぶ。取引業者を選ぶと氏名・住所・電話番号・メールアドレスが掲載ページに公開される。

### 説明(そのまま貼る)

```
秋月電子通商・スイッチサイエンス・M5Stack公式ショップの商品ページに、その商品の価格・在庫表示・掲載状況の履歴を表示します。

■ できること
・商品ページ内に、価格の推移グラフと観測値の一覧を表示します。表示位置は店舗によって異なります。
・前回観測からの価格の変化(値上げ・値下げ)、在庫表示の変化、掲載開始・掲載終了を表示します。
・対応表のある商品では、店舗をまたいだ同一商品・類似商品の記録価格を並べて表示します(類似商品は仕様差を明示し、互換性は保証しません)。
・秋月電子通商・スイッチサイエンス・M5Stack公式ショップの3店舗間で、保存カタログから確認した同一商品を対応づけています。公式ショップは対象バリエーションのUSD参考価格と商品リンクを表示します。全商品の対応付けや最安判定を保証するものではありません。
・M5Stack公式ショップでは、商品構成(バリエーション)を選んでUSD価格と在庫表示の履歴を確認できます。現在の記録価格には、1日1回取得した為替レートによる円換算の参考値を添えます。
・ライト/ダークを切り替えられます。ダークを選ぶと履歴パネルと対応サイトのページ背景に反映され、次のページでも保存した設定を使います。初期表示はライトです。スイッチサイエンスとM5Stack公式ショップのヘッダー、商品画像は元の配色を維持します。

■ 対応サイト
・秋月電子通商(akizukidenshi.com/catalog/g/ 以下の商品ページ)
・スイッチサイエンス(www.switch-science.com/products/ 以下の商品ページ)
・M5Stack公式ショップ(shop.m5stack.com/products/ 以下の商品ページ)
スイッチサイエンスとM5Stack公式ショップは、コレクション経由の商品ページにも対応します。
履歴パネルを表示するのは上記の商品ページです。ダークを選んだときのページ背景は、同じ3店舗のトップ・カテゴリ・検索・商品などの閲覧ページに反映します。パネルを表示しないページでダークを適用しているときは、左下に「ライトに戻す」ボタンを出します。カート・購入手続き・会員ページでは動作せず、店舗本来の表示のままです。

■ データについて
表示する値は、本プロジェクトが公開している静的データ(観測記録)です。店舗の公式データではありません。
3店舗とも約2日に1回、朝5時（日本時間）を基準に観測します。観測と観測の間に起きた変化は記録されません。
価格は記録した販売単位・条件によるもので、在庫数は店舗が表示した数値そのものです。購入の判断は必ず店舗の表示をご確認ください。
M5Stack公式ショップの価格はUSDのまま記録・表示します。円換算は現在の記録価格に添える参考値で、ExchangeRate-APIのレート(Rates By Exchange Rate API)を使います。税・送料・関税・決済時の換算を含まず、支払額ではありません。変化幅・グラフ・他店の価格は記録した通貨のままです。在庫は有無を記録し、数量は表示しません。
M5Stack公式ショップの履歴は2026年9月12日の初回観測から始まります。それ以前の履歴はありません。

■ プライバシー
・個人情報を収集しません。閲覧履歴・入力内容・識別子を送信しません。解析ツールも広告も含みません。
・通信は、公開データ(https://tsuyoshi-otake.github.io/electro-parts)の取得と、USD表示の商品ページでの為替レート(https://open.er-api.com/v6/latest/USD、固定の1URL)の取得だけです。為替レートは1ブラウザーにつき原則1日1回までです。どちらもCookieを送らず、閲覧中のページの情報を送りません。
・取得したデータ・最後の為替レート・取得先URL・テーマの設定のみを、端末内(chrome.storage.local)にキャッシュします。拡張機能を削除すると消えます。
・要求する権限は storage と公開データの取得先のみです。為替レートの取得先はCookieなしの読み取りを公開しているため、権限を追加していません。タブ・Cookie・閲覧履歴へのアクセス権限は要求しません。
・プライバシーポリシー: https://tsuyoshi-otake.github.io/electro-parts/privacy.html

■ オープンソース
ソースコード、データの作り方、設計判断の記録(ADR)はすべて公開しています。
https://github.com/tsuyoshi-otake/electro-parts
```

### 権限の理由

| 項目 | 貼る文言 |
| --- | --- |
| `storage` | `取得した履歴データのキャッシュ(最大200商品のLRU)、円換算の参考値に使う為替レート1件とその再取得時期、データ取得先URL・表示テーマの設定を、利用者の端末内に保存するために使用します。他の用途では使用しません。` |
| ホスト権限 `https://tsuyoshi-otake.github.io/*` | `本拡張機能が表示する価格履歴データ(静的JSON)の取得先です。この1オリジンのみに限定しており、サービスワーカーがCookieを送らずに取得します。` |
| コンテンツスクリプトの対象サイト | `秋月電子通商(akizukidenshi.com)、スイッチサイエンス(www.switch-science.com)、M5Stack公式ショップ(shop.m5stack.com)のトップ・カテゴリ・検索・商品などの閲覧ページだけで実行し、カート・購入手続き・会員ページでは実行しません。商品ページでは履歴パネルを表示し、それ以外の閲覧ページでは保存済みの表示テーマを適用します。ページの内容を外部に送信することはありません。` |
| リモートコードの使用 | **「いいえ、リモートコードは使用していません」**を選ぶ。実行されるコードはすべてパッケージ内にあり、難読化もしていない。 |

### データ使用の開示

Google の定義では「収集」は**利用者の端末外にデータを送信すること**を指す。本拡張機能はどのカテゴリのデータも送信しないので、
個人情報・健康情報・金融情報・認証情報・個人的な通信・位置情報・ウェブ閲覧履歴・ユーザーの操作・ウェブサイトのコンテンツの
**いずれも「収集していない」**と回答する。表示中の商品ページの URL と商品番号はブラウザ内でのみ使用し、送信も保存もしない。
為替レートの取得(`https://open.er-api.com/v6/latest/USD`)は商品・ページ・利用者を含まない固定 URL の読み取りで、
公開データの取得と同じく、利用者のデータを送信するものではない。ホスト権限も追加していない(取得先が CORS で公開読み取りを許可している)。

3 つの証明にはすべてチェックを入れる(いずれも事実):

- 承認された用途以外で第三者にユーザーデータを販売・譲渡していない。
- アイテムの単一用途と無関係な目的でユーザーデータを使用・譲渡していない。
- 信用力の判定や融資目的でユーザーデータを使用・譲渡していない。

プライバシーポリシー URL 欄には <https://tsuyoshi-otake.github.io/electro-parts/privacy.html> を入れる。

## 提出と、落ちたときの読み方

1. `npm run build:extension -- --zip <出力先>` の zip をアップロードする(公開済みの zip と同じもの)。
2. 上の各欄を転記し、審査に提出する。初回は数日かかることがある。
3. 却下されたらメールに**理由の項番**(例: Blue Argon = 権限の過剰要求、Yellow Magnesium = 説明と機能の不一致)が入る。
   直すのは掲載情報かパッケージのどちらかで、判断そのものを議論しない。パッケージを直した場合は版を上げて再アップロードする。
4. 公開後は、ストア側で自動更新が配られる。**zip の手動導入(デベロッパーモード)を続けている利用者は自動更新されない**ので、
   ランディングページと README は両方の導線を残す。
