Electronics Price History

電子部品通販サイトの商品ページで観測した価格・在庫表示・掲載状況の履歴を、静的データとして公開しています。 Chrome 拡張または Tampermonkey 用ユーザースクリプトを入れると、対応サイトの商品ページに履歴パネルが表示されます。

インストール

どちらか一方で足ります。表示されるパネルも取得するデータも同じで、同じソースからビルドしています。 対応サイト(秋月電子通商・スイッチサイエンス・M5Stack公式ショップ・Raspberry Pi Shop by KSY・せんごくネット通販)の商品ページを開くと、購入エリアの下(M5Stack公式ショップでは商品画像の下)に「Electronics Price History」パネルが出ます。Raspberry Pi Shop by KSYでは、一覧や固定リンクから開いた商品の詳細に出ます。

Chrome 拡張

Chrome ウェブストアを開き、「Chrome に追加」を押すだけで入ります。ストア経由で自動更新されます。 ストアの版は審査を通ってから切り替わるので、下の zip より遅れることがあります。

ストアを使わずに、このページの最新版を入れる場合:

  1. electronics-price-history-extension.zip を落として展開する。
  2. Chrome で chrome://extensions を開き、右上の「デベロッパーモード」を入れる。
  3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選ぶ。

zip で入れた場合、自動更新はありません。版が上がったら zip を取り直してください(デベロッパーモードの拡張機能に関する Chrome の警告も毎回出ます)。 権限は設定 1 個の保存と、このサイトからのデータ取得だけです。USD・GBP表示の商品では為替レートも1日1回まで取得します(追加の権限は使いません)。閲覧履歴・タブ・Cookie にはアクセスしません。 詳細はプライバシーポリシーをご覧ください。

Tampermonkey ユーザースクリプト

  1. ブラウザに Tampermonkey を入れる。
  2. electronics-price-history.user.js を開き、Tampermonkey の確認画面でインストールする。

こちらは @updateURL 経由で自動更新されます。

0.7.0: Pimoroni(英国)に対応、円の表示・カード手数料・在庫数グラフの設定

ドルやポンドで記録した店舗の現在の記録価格は、円換算の参考値（約 ￥）を大きく表示し、記録した価格（$・£）をその下に併記するようにしました。閲覧中の商品だけでなく、「店舗別の記録価格」の他店の行と類似商品のカードも同じです。そのため円の店舗の商品を見ていても、他店の行にドル・ポンドの価格が出るときは為替レートを取得します（同じ取得先・1日1回まで）。グラフ・統計・価格変更の一覧・前回からの差は、当時のレートが分からないので記録した通貨のままです。並び順と「最安」の判定は変えていません。パネルの右上に「設定」ボタンを追加しました。円換算の参考値にカードの海外事務手数料を加えるか（初期は加えない）を選べ、料率はカードの種類（2026-11-03 に各カード会社の公表値を確認した11種類）から選ぶか、0〜10% の範囲で入力します。設定はブラウザー内にだけ保存し、カード番号などは扱いません。また、店舗が在庫数を表示している商品（秋月電子通商・Raspberry Pi Shop by KSY）では、記録した在庫数の推移を価格グラフの下に表示します。店舗の切り替えボタンで価格と一緒に隠せ、設定で非表示にもできます。在庫数は店舗が表示した数の記録で、実際の在庫を保証しません。スイッチサイエンス・M5Stack公式ショップの在庫数は、取得している一覧データに含まれないため記録していません（せんごくネット通販は在庫数を表示せず、Pimoroni は在庫数の表示を確認できていません）。

Pimoroni(英国)に対応

6店舗目として、英国の Pimoroni(shop.pimoroni.com)の商品ページに履歴パネルを表示します。日本から開くと店舗は円で表示する日本向けのページ(/en-jp)に切り替えますが、記録するのは店舗の基準通貨である英ポンド(GBP)の価格です。そのためパネルの価格はページの円の表示と一致しません。VAT・送料・関税を含むかは記録しておらず、税区分は「不明」です。現在の記録価格は円換算の参考値で表示します。レートはUSDと同じ1日1回の取得の応答から計算するクロスレート(USD/JPY と USD/GBP から算出)で、通信は増えません。店舗が日本向けページで表示する円とは一致しません。履歴はこの版の公開後の最初の観測から始まります。他店との対応表にはまだ入っていないため、Pimoroni の商品に他店の記録価格は出ません。ダーク表示は店舗ページにも掛かり、ヘッダーは店舗の配色のままです。Chrome ウェブストア版では対象サイトが増えるため、更新時に Chrome が確認を求めることがあります。

ダーク選択を店舗の閲覧ページ（トップ・カテゴリ・検索・商品など）に反映します。カート・購入手続き・会員ページは対象外です。商品写真と在庫・値引きの色分けは保ち、ライトで店舗本来の配色に戻ります。パネルを表示しないページでは左下の「ライトに戻す」を使えます。店舗別の記録価格は閲覧中の店舗を上段、他店を2列に配置し、狭い表示欄では1列に戻します。

0.4.6: 狭い表示欄でのグラフを改善

0.4.5: 3店舗間の同一商品マッピング

対応表のある商品では、同一商品・類似商品・要確認候補を分けて表示します。販売条件まで確認済みの同一商品は、店舗別の履歴を重ねて記録価格差を表示。類似商品は仕様差と商品リンクを別枠に表示し、互換性を保証しません。

0.4.5 の対応表は3店舗間の943組です。同一商品は保存カタログ照合済み810組・未確定候補3組、類似商品は照合済み108組・候補6組、要確認は16組。秋月8,677商品（2026-09-06）、スイッチサイエンス10,343商品（2026-08-02）、M5Stack公式664商品・706バリエーション（2026-09-12）の全行を探索しました。型番一致候補830組を確認し、公式ショップとの同一商品517組を追加しています。現在の全商品・全別名を網羅したものでも、詳細ページの全件再確認でもありません。

M5Stack公式は対象バリエーションのUSD参考記録価格と商品リンクを表示します。税区分は不明で、円換算・最安判定・円価格との差額は表示しません。

差額表示の承認は引き続きATOM LiteとArduino UNO R4 Minimaの2組だけで、他は参考記録価格です。送料・数量割引・販売店独自保証は含まず、現在の最安価格を示すものではありません。関連商品リンクは省略せず、履歴取得は他商品8件までに制限しています。
