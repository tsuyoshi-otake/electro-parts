Electronics Price History

電子部品通販サイトの商品ページで観測した価格・在庫表示・掲載状況の履歴を、静的データとして公開しています。 Chrome 拡張または Tampermonkey 用ユーザースクリプトを入れると、対応サイトの商品ページに履歴パネルが表示されます。

インストール

どちらか一方で足ります。表示されるパネルも取得するデータも同じで、同じソースからビルドしています。 対応サイト(秋月電子通商・スイッチサイエンス)の商品ページを開くと、購入エリアの下に「Electronics Price History」パネルが出ます。

Chrome 拡張

  1. electronics-price-history-extension.zip を落として展開する。
  2. Chrome で chrome://extensions を開き、右上の「デベロッパーモード」を入れる。
  3. 「パッケージ化されていない拡張機能を読み込む」で、展開したフォルダを選ぶ。

この方法で入れた場合、自動更新はありません。版が上がったら zip を取り直してください(デベロッパーモードの拡張機能に関する Chrome の警告も毎回出ます)。 Chrome ウェブストアへの掲載を準備中で、掲載後はストア経由で自動更新されます。 権限は設定 1 個の保存と、このサイトからのデータ取得だけです。閲覧履歴・タブ・Cookie にはアクセスしません。 詳細はプライバシーポリシーをご覧ください。

Tampermonkey ユーザースクリプト

  1. ブラウザに Tampermonkey を入れる。
  2. electronics-price-history.user.js を開き、Tampermonkey の確認画面でインストールする。

こちらは @updateURL 経由で自動更新されます。

0.4.1: 商品照合の拡充と仕様差の表示

対応表のある商品では、同一商品・類似商品・要確認候補を分けて表示します。販売条件まで確認済みの同一商品は、店舗別の履歴を重ねて記録価格差を表示。類似商品は仕様差と商品リンクを別枠に表示し、互換性を保証しません。

0.4.1の対応表は424組。同一商品は保存カタログ照合済み293組・候補3組、類似商品は照合済み108組・候補6組、要確認14組です。秋月8,677商品・スイッチサイエンス10,343商品の保存カタログを型番で探索し、Picoなど13の製品群で具体的な仕様差を表示します。現在の全商品・全別名を網羅したものではなく、全件の詳細ページ確認でもありません。

差額表示の承認は引き続きATOM LiteとArduino UNO R4 Minimaの2組だけで、他は参考記録価格です。送料・数量割引・販売店独自保証は含まず、現在の最安価格を示すものではありません。関連商品リンクは省略せず、履歴取得は他商品8件までに制限しています。

データ

  • マニフェスト: data/v1/stores/akizuki/manifest.json
  • マニフェスト: data/v1/stores/switch-science/manifest.json
  • 商品ごと: data/v1/stores/akizuki/products/<pageKey>.json
  • 最終化済み履歴 DB(SQLite、次回クロールの入力): state/state.json

データについて: 表示される値は、このプロジェクトが観測した時点の店頭表示の記録であり、店舗の公式データではありません。 観測間隔は店舗ごとに異なり(秋月は約1か月、スイッチサイエンスは約1週間)、観測の間に起きた変化は記録されません。価格は記録した販売単位・条件によるもので、在庫数は店舗が表示した数値そのものです。 ユーザースクリプトも Chrome 拡張も Cookie を使わず、閲覧履歴を送信しません。データ取得先は GitHub Pages のこのサイトだけです(プライバシーポリシー)。
