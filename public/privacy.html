プライバシーポリシー

対象: Chrome 拡張機能およびユーザースクリプト Electronics Price History(以下「本ソフトウェア」)。 最終更新: 2026-10-04。

要点

本ソフトウェアは利用者の個人情報を収集しません。閲覧履歴・入力内容・識別子を送信せず、解析ツールも広告も入れていません。 データの販売・第三者提供・目的外利用もありません。

本ソフトウェアが扱う情報

情報用途送信先保存場所
表示中の商品ページの URL と、そのページ内の商品番号・型番 どの商品の履歴を表示するかの判定 送信しません(ブラウザ内で処理します) 保存しません
取得した価格・在庫・掲載状況の履歴データ(公開済みの静的 JSON) パネルの表示と再取得の抑制 — 拡張は chrome.storage.local、ユーザースクリプトは Tampermonkey のストレージ。いずれも利用者の端末内のみ。最大 200 商品(LRU)
取得先の URL 設定(dataBaseUrl、既定値のまま使えます) 自分でホストしたデータを見る場合の切り替え — 同上(1 項目)
米ドルから円への為替レート 1 件(レート値・提供元の更新日時)と、再取得の時期を決める状態(取得日時・失敗回数・次に試す時刻) USD 表示の商品で、記録価格の円換算の参考値を表示し、取得を 1 日 1 回までに抑えるため — 利用者の端末内のみ(1 項目)。レートは再配布しません
表示テーマ(ライト / ダーク) 利用者が選んだパネル表示を維持するため 送信しません 利用者の端末内のみ

通信

本ソフトウェアが行う通信は、次の 2 種類だけです。いずれも拡張機能では取得先をコードで固定したうえで、サービスワーカーが credentials: 'omit'(Cookie を送らない)で取得します。

  • 履歴データの取得: tsuyoshi-otake.github.io(GitHub Pages)の公開済み静的 JSON。
  • 為替レートの取得: ExchangeRate-API の https://open.er-api.com/v6/latest/USD(固定の 1 URL、API キーなし)。米ドル表示の商品ページを開いたときだけ、 1 つのブラウザーにつき原則 1 日 1 回まで取得します(取得に失敗した場合は 1 時間から 24 時間までの間隔を空けて再試行します)。 この URL は商品・ページ・利用者のいずれも含まない固定値で、閲覧中のページの情報は送りません。 提供元の規約でレートの再配布が禁止されているため、本プロジェクトのサーバーを経由せず、各ブラウザーが直接取得します。

商品ページを開いた店舗のサーバーに対して、本ソフトウェアが追加のリクエストを送ることはありません。

取得先である GitHub Pages には、通常の Web サーバーと同様にアクセスログ(IP アドレスなど)が GitHub のプライバシーステートメントのもとで記録され得ます。 これは GitHub による運用であり、本プロジェクトはそのログを取得も利用もしていません。 為替レートの取得先である ExchangeRate-API にも、同様にアクセスログ(IP アドレスなど)が提供元の方針のもとで記録され得ます。本プロジェクトはそのログも取得・利用していません。

権限

  • storage: 上記のキャッシュ・為替レート・設定の保存にのみ使います。
  • https://tsuyoshi-otake.github.io/*: 履歴データの取得にのみ使います。
  • 為替レートの取得先は、Cookie なしの読み取りを誰にでも許可している公開 API のため、追加の権限を要求しません。
  • コンテンツスクリプトは、秋月電子通商・スイッチサイエンス・M5Stack公式ショップのトップ・カテゴリ・検索・商品などの閲覧ページで実行します。保存したテーマを閲覧ページへ適用するためです。カート・購入手続き・会員(アカウント)ページでは実行しません。価格履歴の取得とパネル表示は商品ページに限定します。
  • タブ・Cookie・閲覧履歴・ダウンロード・任意サイトへのアクセス権限は要求しません。リモートコードの読み込みや実行もありません。

データの削除

拡張機能を削除すると、chrome.storage.local に保存されたキャッシュと設定も削除されます。 ユーザースクリプトの場合は Tampermonkey からスクリプトを削除してください。端末外に保存されたものはありません。

その他

  • 本ソフトウェアは個人が公開しているものであり、秋月電子通商・スイッチサイエンス・M5Stackその他の販売店の公式製品ではなく、これらとの提携関係もありません。
  • 表示される値は本プロジェクトが観測した時点の店頭表示の記録であり、店舗の公式データではありません。
  • 本ポリシーを変更する場合は、このページと リポジトリで更新日とともに公開します。
  • 問い合わせ: GitHub Issues(Chrome ウェブストアの掲載情報にも連絡先を記載しています)。

English summary

Electronics Price History collects no personal data. It does not transmit browsing history, page content, keystrokes or identifiers, and contains no analytics, advertising or tracking. It reads the URL and the product number of the product page you are viewing, in the page, to decide which history to show; that never leaves your browser.

It makes two kinds of network request, both from the extension's service worker with credentials: 'omit' and both to fixed addresses: a read of the published static JSON dataset at https://tsuyoshi-otake.github.io/electro-parts, and, on product pages with US dollar prices, a read of one fixed URL, https://open.er-api.com/v6/latest/USD (ExchangeRate-API, no key), at most about once a day per browser, to show a yen reference value. That URL carries nothing about you or the page. The provider's terms forbid redistributing its rates, so each browser fetches them directly. Fetched data, the last rate and settings are cached in chrome.storage.local on your own device (up to 200 products, LRU) and are removed when you uninstall the extension. GitHub and ExchangeRate-API may record standard server logs; this project neither receives nor uses them. Permissions are limited to storage and the dataset origin; the rate API allows cookie-less reads from any origin and needs no permission. No remote code is loaded or executed. No data is sold or shared.
