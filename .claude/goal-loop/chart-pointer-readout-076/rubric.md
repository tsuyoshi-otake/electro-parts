# Goal: Charts show the line's value under the pointer (Issue #76, release 0.7.6)
Workdir: C:\Codes\tsuyoshi-otake\electro-parts (Git Bash: /c/Codes/tsuyoshi-otake/electro-parts; `cd` there first in every Bash call)

The owner asked for a label that appears while the mouse is over a chart and shows the value of the line at that point. Scope: the single-store price chart, the store comparison chart and the stock count chart (`userscript/ui/chart.ts`, `userscript/ui/chartReadout.ts`). Decision record: `docs/adr/0028-chart-pointer-readout.md`. The working tree holds uncommitted changes on branch `feat/chart-hover-readout`; judge the working tree.
