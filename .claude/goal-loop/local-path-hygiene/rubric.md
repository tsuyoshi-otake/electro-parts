# Goal: No tracked file cites an absolute local user path; evidence is cited as `~/tmp/...`, and CI fails if such a path comes back (Issue #59)
Workdir: the repository root (`electro-parts`), branch `chore/remove-local-paths`, changes uncommitted.

Shell note: Git Bash on Windows. Run every command from the repository root. Do not modify any file.

## Criteria
- C1: No absolute user path is left in tracked files. Verify: `git grep -nIE 'C:[\\/]+Users[\\/]+[A-Za-z0-9._~-]' -- .; echo rc=$?` and `git grep -nIE 'DEVELO~1|AppData' -- .`. Expect: the first prints only `rc=1`; every line of the second names the bare pattern in a hygiene rule or check (no directory follows `C:\Users`), not a real path.
- C2: The replacements change only the path prefix. Verify: `git diff origin/main --stat` and `git diff origin/main -U0`; for each removed line containing an absolute home-directory `tmp` prefix (drive letter, `Users`, the account name and `tmp`, separated by `/` or `\`), replace that prefix with `~/tmp/` and the backslashes of the rest of that path with `/`, then compare with the added line at the same position. Expect: every rewritten removed line equals its added line; no other line is removed; added lines that are not replacements appear only in `.github/workflows/ci.yml`, `.claude/memory/journal.md` (appended at the end) and this rubric.
- C3: The CI guard catches the old tree and passes the new one. Verify: read the step "Tracked files must not hold local user paths" in `.github/workflows/ci.yml`; run its `git grep` pattern against `origin/main` (`git grep -nIE '<pattern>' origin/main -- . | wc -l`) and against the working tree. Expect: the pattern equals the one in C1; it finds at least 19 lines in `origin/main` and none in the working tree; the step fails (`exit 1`) when there are hits; its comment does not match its own pattern.
- C4: The workflow stays well formed. Verify: `sed -n 45,80p .github/workflows/ci.yml` and `git diff origin/main -- .github/workflows/ci.yml`. Expect: the new step sits inside the same job's `steps:` with the same indentation as its neighbours (`      - name:` and `        run: |`), the block body is indented consistently, and no existing step changed.
