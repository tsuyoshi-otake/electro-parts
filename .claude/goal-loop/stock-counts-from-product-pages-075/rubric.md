# Goal: Record M5Stack and Switch Science stock counts from product pages, and show 「100+」 in 0.7.5 (Issue #74)
Workdir: the repository root (electro-parts). Use Git Bash. Nothing in this rubric contacts a live store.

## Criteria
- C1: Types and the full unit suite pass. Verify: `npm run typecheck` then `npm test`. Expect: both exit 0; vitest reports 0 failed tests.
- C2: The CI guards hold. Verify: `grep -rniE 'akizuki|aitendo|switch[-_ ]?science|akizukidenshi|m5stack|ksy|sengoku|pimoroni' src/core src/db src/publisher src/pipeline userscript/core userscript/ui | grep -vE ':[0-9]+:\s*(//|\*|/\*)'`; `git grep -nIE 'C:[\\/]+Users[\\/]+[A-Za-z0-9._~-]' -- .`; and the same local-path pattern over `git ls-files --others --exclude-standard`. Expect: all three print nothing.
- C3: The page readers accept only a page they recognise. Verify: `npx vitest run tests/unit/store-product-pages.test.ts`; read `src/collectors/m5stack/productPage.ts` and `src/collectors/switch-science/productPage.ts`. Expect: tests pass; the M5Stack reader rejects a page for another handle and a script/option disagreement and maps a negative count to `null`; the Switch Science reader requires the canonical URL of the target, exactly one 「在庫数」, and treats a `+` other than 100 as unrecognised.
- C4: The recording rules match ADR-0027's table. Verify: read `withPageQuantity` in `src/adapters/productPageInventory.ts` and the `quantityUnobserved` branch in `src/db/importSnapshot.ts`; run `npx vitest run tests/unit/product-page-inventory.test.ts tests/db/import.test.ts tests/integration/switch-science-crawl.test.ts tests/unit/m5stack.test.ts`. Expect: no section → `not_exposed`; read count → that count; read `null` → `quantity: null` without `quantityUnobserved`; unread and `purchasable === false` → `quantity: null` without `quantityUnobserved`; any other unread offer → `quantityUnobserved: true`; the importer adds no inventory change point when `quantityUnobserved` is true; all listed tests pass.
- C5: Installed 0.7.4 can still read the published data. Verify: in `src/publisher/contract.ts` read `CONTRACT_VERSION` and the inventory validator; read the 0.7.4 client's contract check with `git show 3606d26:userscript/core/dataClient.ts` (and any file it imports for the version check). Expect: contract version is 1.2.0 (same major as before); inventory points are still `[t, quantity]`; `cappedAt` is an optional series field; the 0.7.4 client compares only the major version and does not reject unknown object fields.
- C6: The configured load stays within ADR-0027. Verify: read `config/m5stack.json`, `config/switch-science.json`, `src/collectors/productPageInventory.ts` and `docs/adr/0027-stock-counts-from-product-pages.md`. Expect: the `productPages` values (`shards`, `maxPages`, `maxFailures`, `maxMinutes`) and `maxRequests` in each config equal the ADR's table; `minIntervalMs` is at least 1500 in both configs; the stage stops on 429, after 3 consecutive non-404/410 fetch failures, past `maxFailures`, at `maxMinutes`, and when the request budget is spent.
- C7: Userscript and extension 0.7.5 show 「100+」. Verify: `npx vitest run tests/userscript/chart.test.ts tests/userscript/comparison-panel.test.ts`; `node --import tsx scripts/build-userscript.ts --out dist/site` then `grep -m1 @version dist/site/electronics-price-history.user.js`; `node --import tsx scripts/build-extension.ts --out dist/extension` then read `dist/extension/manifest.json`. Expect: tests pass; both versions are 0.7.5; `userscript/ui/panel.ts` and `userscript/ui/chart.ts` format counts through `formatStockCount` with the series' `cappedAt`.
- C8: The saved-page E2E suite passes. Verify: `npm run test:e2e`. Expect: exit 0, 0 failed. Afterwards list processes whose command line contains `vitest`, `playwright` or `ms-playwright` (ignore your own shell). Expect: none.
- C9: The decision is documented and linked. Verify: read `docs/adr/0027-stock-counts-from-product-pages.md`, `docs/adr/README.md`, line 3 of `docs/adr/0014-shopify-catalog-api-over-html.md`, `docs/adr/0026-yen-headline-card-fee-and-stock-chart-settings.md`, and the 0.7.5 section of `public/index.html`. Expect: ADR-0027 records the owner's 2026-11-04 decision on the M5Stack "spider, crawl, or scrape" clause and its remaining risk; it is in the index; ADR-0014 and ADR-0026 link to it as amending them; the landing page's 0.7.5 section says Switch Science refreshes about every 8 days and that 0.7.4 shows 「100」 for 「100+」.
